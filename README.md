# 3d-raster
3D software rendering engine with support for texture sampling, written from scratch in C++ using SDL2. This project is an exploration of the techniques that make up the basis of raster based rendering technology.

Note that this engine is NOT hardware accelerated and runs fully on the CPU as a single threaded process.
