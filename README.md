# 3d-raster
3D rendering engine I am working on, written in C++


## HOW TO COMPILE

The only dependancy is libsdl2-dev.

### LINUX
1. use your package manager to install `libsdl2-dev`. On debian that is
```
sudo apt install libsdl2-dev  
```

After installing use the makefile to build. Go to the project folder and execute `make`.
